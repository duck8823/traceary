# #2472 Shared headless registry

## Requirement summary
Implement the single UI-independent project/worktree/target registry backend accepted by R0 (merge aa08a19326d0a2d0cbdd315476262fa8afbf4211). No daemon process, UI, native agent/model invocation, host configuration or core store/schema mutation. Later launch consumes Registry.Resolve to revalidate an immutable target, and D2 consumes the same registry service.

## Conceptual model / responsibility
- Project: canonical Git common-dir identity, immutable ID and filesystem witness.
- Worktree: canonical worktree/store plus project, immutable ID and physical witness. Target is an immutable worktree snapshot plus an explicit profile ID, allowing Claude and Codex to share one registered worktree; do not persist one host choice as a global worktree selection. Switching caller selection has no side effect on a stored target or running process.
- Registry aggregate (domain/runtime): duplicate/membership/identity rules, 100 projects/1000 targets bounds, explicit remove plans and optimistic revision binding; private state with snapshot copies.
- Registry service (application/runtime): object-level register/list/resolve/export/plan-delete/apply-delete methods, repository transaction + resolver ports. Compare existing MemoryUsecase object-oriented method granularity; do not split one usecase per action.
- Native resolver and owner-private versioned JSON store (infrastructure/runtime): canonical filesystem/Git checks, UID/device/inode witness, strict schema, bounded durable atomic update, per-file OS lock. Existing SQLite and registry-independent runtime state are untouched.

## Boundaries and behavior tests / TDD
Resolve only canonical registered worktree roots, verify `git --git-common-dir` belongs to registered project, canonical store is an owned regular file, and compare profile/physical identities on every Resolve. Symlink aliases canonicalize consistently at registration; later retarget/replacement rejects rather than silently rebinds. Git commands do not inherit repository-local env variables.
Public external-package tests first: duplicate alias, foreign repository, missing/replaced path, store/profile mismatch, bounds, immutable snapshot, explicit delete plan/cancel/stale revision, strict newer/invalid schema, wrong permissions/symlink, concurrent independent writers, overflow preserves old file. Test fixtures never use user stores or start native AI CLIs.

## Validation / rollback

Disable mutations and preserve/export metadata to roll back; never remove Git worktrees/branches/store files. Registry-only PR closes #2472, not parent #2432/#2414. No UI framework dependency.
