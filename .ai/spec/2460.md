# #2460 Owner-scoped local daemon IPC

## Accepted checkpoint / requirement
R0 was human-accepted/merged; this implements its transport slice after shared registry. Two owner-private Unix sockets (daemon.sock management, observations.sock derived metadata only); no TCP, arbitrary exec/file methods, PTY ownership, model/authentication changes or Session lifecycle. Foreground `traceary daemon serve` and bounded `daemon status --json` must not initialize/query the core store. Native hook CLI integration remains #2466, not fabricated by transport acceptance.

## Structure-Behavior design
High / security and public protocol. Concepts: EndpointRole fixed by socket, VersionHandshake, bounded canonical frame, ServerEpoch, PendingObservationQueue and typed Status. Infrastructure owns framing/Unix peers/path witnesses/listeners; application owns consumer-facing daemon/observation ports; presentation parses flags/JSON and main composes dependencies. No generic dispatch/reflection/shell endpoint.

Wire v1: 4-byte big-endian length + canonical UTF-8 JSON, max 65536 bytes. Hello has protocol_version/request_id/operation=hello/role; every subsequent request carries version and bounded unique request_id. Named status management method; observation socket permits only observe with a fixed metadata-only object. Unknown/duplicate/case-aliased fields, unknown version, invalid roles/types/truncation/oversize reject before mutation. Status is listening readiness/capabilities, not agent liveness. Default no observation consumer => unsupported, never falsely accepted state.

Root is no-follow-walked, owned 0700 with pinned descriptor witness; socket 0600, path length checked before bind, actual peer UID checked in BOTH directions (Darwin LOCAL_PEERCRED/Xucred (native peer API; x/sys does not export getpeereid on Darwin), Linux SO_PEERCRED for CI; other platforms unavailable). Existing socket/path always refuses (no stale auto-unlink). Listener cleanup unlinks only matching owner/device/inode and current pinned root, never a replacement. Disable net.UnixListener auto-unlink. Initial endpoint creation is all-or-nothing.

Admission: max 32 simultaneous management connections; observation connections separately bounded at 32; 256 observation frames AND 8 MiB queue, single consumer worker, overflow busy. Constructor tuning may only tighten R0. Server frame/handshake deadlines bound slow clients. Client total optional-delivery budget 250ms from start (including filesystem checks/dial/handshake/write/ack); isolate potentially blocking path inspection behind a bounded process-wide gate so timeout cannot leak unbounded goroutines or late delivery. No secret/raw frame logging. Same-UID hostile process/ACL isolation is NOT claimed.

## Implementation checkpoint
Native Darwin transport and CLI subprocess tests now exercise real owner-private Unix sockets; Linux SO_PEERCRED is the CI adapter. Windows cross-build passes with transport explicitly unsupported. Frame fuzz smoke passed (3 seconds, 294400 executions; not exhaustive certification). Final scoped race command covers daemon, registry, pillar inventory and fuzz seeds; 30 repeated admission/slow-frame race runs passed after fixing a test-readiness slot-release race, without changing server limits. Lint reports zero issues. Core-store initialization remains outside daemon-only composition and HOME-unset process tests verify the boundary.

Additional full CLI race run exceeded the Go default ten-minute timeout in unchanged SQLite-backed CLI tests; a detached exact-base comparison is in progress. This is not a successful validation or a proven pre-existing failure. Full standard tests and fresh final-head CI remain required independently. Same-UID fixtures do not certify different-UID/ACL boundaries; no native AI hosts were invoked.

Process friction: outer sandbox cannot bind Unix sockets, so scoped native tests use approval-capable execution while preserving the implementation and reviewer sandbox. Windows build dependencies use a bounded private temporary module cache, pinned go.sum and readonly module mode; no source/module manifest updates.
