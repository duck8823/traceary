# #1879: measure the two v0.34-unmeasurable fold/wake rows

## Policy

- A session is worth folding iff it has a `session_refinements` row OR `SUM(event_metadata_projection.body_stored_bytes) >= consolidation.threshold_bytes` (default 64 KiB). That is the same crossing that fires the stop-hook ask, plus already-folded sessions whose bodies were later discarded.
- `go run ./cmd/store-benchmark --fold-gates --db PATH` is required. The default live store (`~/.config/traceary/traceary.db`) is refused.
- Measurement uses metadata tables only (no event bodies). Wake is counted per `sessions.client` with the same top-level + `has_agent_reasoning` rule as injection. Content is a structural sample, not a semantic parse of motivation/change.
- Live-store figures stay out of bar. The v0.34 baseline remains 0 / 27,552.

## Non-goals

- Querying the live store.
- Evaluating every #1873 gate threshold.
- Changing wake injection or consolidation behavior.
