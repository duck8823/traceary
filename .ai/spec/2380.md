# Pre-commit Git environment isolation

- Motivation: Git hook repository-local environment leaks into Go fixture subprocesses. Normal commit failures reproduced despite outside-hook suite success; fixture git init changed common core.bare, which was restored. Avoid skipping required validation.
- Scope: retain committing-worktree context for package/staged-file selection and formatting; remove Git-reported local environment variables only in the test subprocess. No repository detection, production hooks, auth, or gate semantics changes.
- Low-risk structure: pre-commit owns subprocess environment; Git owns the variable-name list; tests own fixture repositories. No generic framework.
- TDD: four hermetic normal/linked/failed-test/failed-format cases fail before change; after change they must pass, including exact selected package execution and mandatory nonzero propagation.
- Verification: Python contract suite, Bash syntax, staged selector, Go tests and normal hook with no bypass. Paired user-facing docs unchanged because invocation and gates are unchanged.
- Rollback: restore prior hook from backup only after preventing unsafe fixture inheritance; never rerun a polluted normal commit against a real repository.
