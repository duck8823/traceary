## Structure-Behavior Design Note

### Requirement summary
- Purpose: prevent automatic Traceary summary output from filling the agent UI.
- Current behavior: wake injection defaults to 8 KiB, while a consolidation reminder embeds an entire previous refinement.
- Expected behavior: the default wake payload is at most 2 KiB and reminder context contains at most a compact 240-rune preview.
- Out of scope: changing explicit operator-configured budgets, stored refinement content, or manual full-context commands.

### Conceptual model
| Concept | State | Behavior | Constraint / Invariant |
|---|---|---|---|
| Wake injection budget | default or operator configured | bounds injected bytes | explicit config remains authoritative |
| Previous-summary preview | stored summary | collapses whitespace and truncates for display | at most 240 runes; storage is unchanged |

### Responsibility assignment
| Responsibility | Owner | Reason to change | Not owner / reason |
|---|---|---|---|
| Default wake payload size | `presentation` config | operator-facing default | query service; it only selects summaries |
| Reminder preview formatting | consolidation CLI formatter | owns emitted hook text | domain/usecase; no storage rule changes |
| Published behavior | bilingual environment/hook docs | public configuration contract | release tooling |

### Boundaries / interfaces
| Boundary or interface | Consumer | Hidden detail | Error contract |
|---|---|---|---|
| `wake_injection.budget_bytes` | hook operators | selection implementation | zero/negative still disables |
| consolidation reason text | AI host UI | full stored refinement | formatting remains infallible |

### Behavior tests
| Behavior | Given | When | Then | Level |
|---|---|---|---|---|
| smaller default | no configured budget | config is loaded | budget is 2048 bytes | unit |
| bounded reminder | long multiline Unicode summary | reason is formatted | preview is single-line and <=240 runes | unit |
| explicit override | configured budget | config is loaded | configured value is unchanged | existing unit |

### TDD plan
| Behavior | Red | Green | Refactor target |
|---|---|---|---|
| default bound | expect 2048 in config tests | change constant/comments | stale 8 KiB wording |
| reminder bound | add long multiline summary case | add display-only compaction helper | duplicated truncation logic |

### Risks / rollback
- Procedural risk: reducing the default may inject fewer historical summaries; operators can set a larger explicit budget.
- Premature abstraction: keep the preview helper local to consolidation formatting.
- Migration / compatibility: no config or storage migration; explicit values retain their meaning.
- Rollback trigger: agents lose required context despite loading the refinement skill.
