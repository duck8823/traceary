# #1811: calibrate storage gates against synthetic corpora

## Policy

- Five seeded corpora (tiny, enormous, cjk, entropy, repetitive) generated as code. No sample data in the repository.
- `go run ./cmd/store-benchmark --calibrate-gates DIR` writes one store per kind and `calibrate.json` (`traceary.store-gate-calibrate/v1`).
- Measurement uses production `EventDatasource.Save`, `CapacityInspector`, and `OperatorCostInspector`.
- Search-index amplification stays `unmeasured` without a completed projection generation.
- The five-corpus job is not part of `go test ./...`. Tests cover generator determinism and a tiny calibrate run.

## Non-goals

- Live-store measurement.
- Changing the 2.16x search-amplification fallback.
