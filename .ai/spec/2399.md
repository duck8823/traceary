# P1 Structure-Behavior Design Note

## Requirements and checkpoint
Approved parent checkpoint: ADR 2026-09-27-resumable-session-boundaries and merged design PR #2398. This public output change is HIGH risk. Session identity groups logs; handoff and compact-only must not reject old unended sessions. Remove generated STATUS, preserve human prose and existing selection/content. No write-side, SQL, schema, parent inference or host changes.

## Concepts and responsibilities
| Concept / owner | Behavior and invariant |
| --- | --- |
| Workspace resolution / existing query service | Existing latest ordering, tie and parent-workspace fallback remain unchanged; lifecycle is not eligibility. |
| ContextPack / application builder | Aggregate existing compact, refinement, commands and memories; no lifecycle status carrier. MemoryAsOf applies only to memories. |
| Handoff / CLI formatter | Format content without generated lifecycle scaffolding; never rewrite summary text. |
| Deprecated flags / context CLI parser | Parse existing duration/bool syntax, keep mode validation; explicit use warns only on stderr, once per flag. |

## Boundaries and audit
ContextUsecase.Handoff continues returning Optional[ContextPack]; builder is the same aggregation unit as current ContextUsecase, not a new use case. Legacy HandoffSummary conversion loses only status. SessionSummary status remains for other consumers. sessionSummaryOutput has no runtime callers (only its isolated serialization test), so delete that dead DTO/test. Raw context JSON uses event output and is unchanged. No context JSON contract is invented.

## Observable tests and TDD

Green: delete eligibility/requery/status plumbing, add parser-level warning. Preserve existing compact/refinement/coverage/memory/command and workspace tests, add old-unended fixtures. Refactor: retain legacy criteria fields as ignored compatibility API, document their no-op meaning.

## Migration, rollback and split
This is P1 only; execution guards and producer cutover remain later packages. Actual flags stay accepted for the documented transition; removal is a separate approved public change, not scheduled here. Revert this commit if selection content disappears or downstream output breakage is unapproved; stored logs/schema are unchanged, but restoring old stale restrictions needs operational acceptance. No generic lifecycle/token framework is added.

## Red evidence and self-review
The first baseline attempt hit the host cache permission boundary. With writable GOCACHE, temporarily restoring only the original stale gate caused `TestContextUsecase_Handoff/includes_old_unended_session_regardless_of_legacy_stale_options` to fail with `Handoff(stale default) returned empty, want pack`; deleting that gate passed. Formatter deletion is structural, not a string replacement. Existing builder aggregation and resolution boundaries remain, with no new storage dependencies. Legacy criteria still carry options solely for internal compatibility.

## Public deprecation checkpoint refinement
Independent final-head review found no MUST/runtime regression. Main classified the public notice policy/doc findings as fix_now: use the existing localized DEPRECATED renderer, one aggregate notice per invocation, no replacement, and removal target v0.54. Current released v0.52 is followed by a full v0.53 transition; v0.54 is a conservative target, not permission to remove flags or publish a release. Removal requires a separate PR/checkpoint. Both flags remain parsed no-ops and invalid mode invocations remain silent. Raw context JSON is the existing object envelope, not a top-level event list. Direct legacy-ended selection uses a test-local filtering query adapter to verify SID/workspace constraints.
