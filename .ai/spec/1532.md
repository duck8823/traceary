# #1532 Partial usage diagnostics

## Requirement summary

Traceary must preserve body-free, provider-reported usage evidence without
inventing counters, time, or command intent. A collection failure is a capture
diagnostic, not a rewrite of the supervised child process result.

## Conceptual model

A `UsageObservation` has two independent facts:

1. **availability** of each counter dimension (`known`, including zero, or
   `unavailable`), and
2. **reportability** of the observation boundary (a source timestamp or a
   documented Traceary ingestion time for a supervised stream).

An unavailable observation is not a successful usage observation with zeros.
It is explicit evidence that the selected source could not provide counters.

## Responsibilities and boundaries

| Boundary | Responsibility | Must not do |
| --- | --- | --- |
| Stream/source adapter | Parse body-free terminal metadata, preserve known fields, reject malformed or negative counters, select a reportable timestamp | Infer omitted fields, retain bodies, or manufacture a provider timestamp |
| Capture use case | Map source samples to finalized observations and make unavailable fallback identities idempotent | Classify CLI arguments or alter child execution |
| `session run` presentation | Classify host command options only before `--`, supervise and finalize the child, invoke capture diagnostics | Treat a capture decode failure as a different child exit status |
| Report/query projection | Render known and unavailable dimensions exactly as persisted | Convert unavailable to zero or epoch-time usage |

## Behavioural examples

- Codex `turn.completed.usage` with only `cached_input_tokens: 0` and
  `reasoning_output_tokens: 3` persists those two known values; other
  dimensions remain unavailable. A negative value rejects the terminal.
- `codex exec -- --json` does not enable headless usage capture because the
  literal belongs to the child argument vector.
- A malformed supervised Grok stream records the same excluded unavailable run
  observation on every replay and leaves a child exit of `7` as `7`.
- Available Claude transcript usage without an RFC 3339 timestamp is rejected;
  a Traceary-owned headless result can use its UTC ingestion time. An
  unavailable transcript terminal without a provider timestamp uses the
  inspected local transcript file time, never the Unix epoch, so a period
  report does not mix unrelated epoch evidence into a current release window.
- A partial Codex rollout cumulative snapshot preserves each known
  non-negative dimension independently. Omitted dimensions remain
  unavailable; a decrease in a dimension known in both snapshots makes the
  entire turn unavailable rather than emitting a negative delta.
