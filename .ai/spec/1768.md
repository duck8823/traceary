# #1768: what a workspace conflict is for

## Policy

- A conflict is an operator-reviewable `(session_id, workspace)` pair. Classification stays diagnostic and never blocks ingest.
- Keep `traceary store workspace-alias`. Do not deprecate it. Auto-alias is forbidden.
- Report observation-row counts as volume. Add distinct current-conflict pair counts. Sample one latest row per pair and include `workspace`.
- Do not query the live store. Do not change row-based `conflict_rate`.

## I/O

- `WorkspaceIdentityReport.ConflictPairCount`
- `WorkspaceIdentitySourceReport.ConflictPairCount`
- `WorkspaceConflictSample.Workspace`
- `traceary report workspace-identity` text prints `conflict_pairs`.
- Tests drive the real report against a scratch SQLite file (repeated rows of one pair plus a second pair).

## Non-goals

- Removing `store workspace-alias`.
- Live-store review of the 147 pairs.
- Family-wide or path↔remote normalisation rules.
