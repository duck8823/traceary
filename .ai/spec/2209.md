## Structure-Behavior Design Note

Risk: **Medium** — host-behavior gated. Do not start with adapter rewrite. Do not synthesize `session_ended`.

### Requirement summary
- Purpose: Grok Build 1.0.5 wrote zero Traceary events after 0.45.0 refresh. `grok plugin list` Source pointed at an **absent** directory; doctor still PASS at 0.44.0 from installed-plugins cache.
- Expected: (a) a **new** Grok process records wired events (`session_started` plus prompt or transcript), **or** matrix/docs honestly mark the probed mode as not emitting — not both. (b) Doctor FAILs/WARNs when `grok plugin list` Source is a **local filesystem path** that does not exist; a present 0.45.0+ install PASSes. URL sources are not “missing”.
- Out: synthesizing session_ended from process exit / TUI quit / `-p` exit. Changing Claude/Codex/Kimi/Gemini/Antigravity contracts. Interactive Antigravity TUI. Live home store with repo-built binary.

### Conceptual model
| Concept | Behavior | Constraint |
|---|---|---|
| Plugin list Source | inventory field from `grok plugin list --json` | local path → Stat; http(s) git URLs skip existence |
| Missing source | local Source path does not exist | FAIL or WARN with reinstall hint (`scripts/install-grok-plugin.sh`); must not PASS version |
| Cache copy | `~/.grok/installed-plugins/*/plugin.json` | version PASS is insufficient if Source is gone |
| Capture | host emits hooks → wrapper → adapter | only change adapter if probe shows host emission Traceary dropped |
| SessionEnd | already `available` | unchanged unless a new probe shows emission |

### Responsibility
| Owner | Does | Does not |
|---|---|---|
| `probeGrokDoctorState` / grok doctor checks | Stat local Source; surface missing-source | rewrite grok inventory |
| matrix.json + host-coverage docs | record probed Grok version / headless vs TUI | invent wired if probe is empty |
| hook_grok.go / traceary-grok.sh | only if host payload is present and dropped | process-exit closer |
| leftover grok-transcript jobs | observe during probe | new ticket unless they block capture |

### Probe plan (throwaway `TRACEARY_DB_PATH`, brew CLI)
1. New Grok process after install (not a resumed leader). Isolated `-p` and, if possible, a short TUI.
2. `traceary list --db-path $TMP --json --fields id,ts,kind,session --limit 20`
3. If TUI records and `-p` does not: document `-p` like SessionEnd `available`.
4. If neither: dump hook field names only (no bodies); check `GROK_PLUGIN_ROOT`, wrapper exit, hooks.json load. Then matrix/docs.
