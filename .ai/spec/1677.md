# Issue 1677: attestation chain over instructions and command identity

## Structure-Behavior Design Note

Risk: **Medium** — new append-only table, write-path coupling, migration,
compact interaction. Not High: no public CLI tree, no live-store backfill,
no doctor/anchor (those are #1678).

### Requirement summary

- 目的: 人間の指示（`prompt`）とコマンド同一性（`command_text` +
  `input_text` + timestamps）を改ざん検知できるハッシュ鎖にする。
- 現状: `events` / `command_audits` は上書き可能な行。`output_text` は
  #1675 / spec D3 で attested 集合の外。
- 期待する振る舞い:
  - 新しい `prompt` 保存と `SaveWithAudit` が、同じ transaction で 1 link を足す
  - 鎖は `prev → content → link`。空店の head は genesis
  - `output_text` を変えても content hash は変わらない
  - 歴史行は backfill しない（migration は空テーブルだけ。30 GiB を open で歩かない）
  - compact は attested な event を DELETE しない
  - 検証関数は出荷コード。doctor / ファイル anchor は #1678
- 非対象: `traceary attest` ツリー、#1678 anchor、歴史 backfill、
  transcript / note の証跡、親 #1693 の close、tag。

### Conceptual model

| Concept | State | Behavior | Constraint / Invariant |
|---|---|---|---|
| Attested record | prompt body, or command_text+input_text | 追記時にだけ hash | output_text は入力に入らない |
| Content digest | SHA-256 of canonical v1 fields | 書き込み時に計算。verify は store から再計算 | 長さ付きフィールド。created_at は保存文字列 |
| Link | seq, event_id, kind, content, prev, link | head を読んで 1 行進める | link = H(prev, content)。event_id UNIQUE |
| Head | singleton (head_sha256, seq) | 各 append で更新 | 空なら genesis。seq = 行数 |
| Unattested history | 移行前の行 | 鎖に入らない | 「全 prompt が link を持つ」は要求しない |
| Genesis | 固定 digest | 最初の prev | `SHA256("traceary.attest.genesis.v1\n")` |

### Responsibility assignment

| Responsibility | Owner | Reason to change | Not owner / reason |
|---|---|---|---|
| 何を hash するか | `domain/attestation` の純関数 | 証跡集合が変わる | SQL / CLI は知らない |
| いつ足すか | `persistEventDelivery` の insert 成功後 | 書き込み経路が変わる | usecase は SQL を持たない |
| 鎖の保存と検証 | sqlite adapter | スキーマ | domain は DB を見ない |
| attested 行を消さない | compact copy-filter / dedupe apply | 削減規則 | doctor は #1678 |
| 公開コマンド | 無し | — | `traceary attest` を作らない |

### Boundaries / interfaces

| Boundary or interface | Consumer | Hidden detail | Error contract |
|---|---|---|---|
| `attestation.ContentSHA256` / `LinkSHA256` | sqlite write + verify | 正規化バイト列 | 不正 kind は error |
| `appendAttestationLink` | `persistEventDelivery` | head lock は SQLite writer | テーブル未作成（古い fixture）は no-op |
| `VerifyAttestationChain` | テスト、#1678 | 再 decode | 切れ・再計算不一致は error |
| `events(id) ON DELETE RESTRICT` | dedupe / compact | cascade 禁止 | attested DELETE は失敗するので apply が先に skip |

### Hash contract (v1)

Prompt:

```
traceary.attest.v1
kind prompt
event_id <id>
created_at <stored RFC3339Nano>
body <decimal byte length>
<raw body bytes>
```

Command (no output field exists in the encoding):

```
traceary.attest.v1
kind command
event_id <id>
created_at <stored RFC3339Nano>
command_text <decimal byte length>
<raw command bytes>
input_text <decimal byte length>
<raw input bytes>
```

Link: `traceary.attest.link.v1\nprev <64 hex>\ncontent <64 hex>\n`

### Behavior tests

| Behavior | Given | When | Then | Level |
|---|---|---|---|---|
| output は hash に入らない | 同じ command/input、違う output | ContentSHA256 | digest が等しい | domain |
| prompt と command は別 | 同じ id 文字列でも kind が違う | ContentSHA256 | digest が違う | domain |
| 空店の verify | 新規 init | VerifyChain | genesis head、0 links | sqlite |
| 書き込みが鎖になる | Save prompt のあと SaveWithAudit | VerifyChain | seq=2、再計算一致 | sqlite |
| command 改ざんを拒む | 保存後に command_text を UPDATE | VerifyChain | error | sqlite |
| output 改ざんは鎖を壊さない | 保存後に output_text を UPDATE | VerifyChain | 成功 | sqlite |
| 歴史は必須にしない | 移行前相当の prompt を生 INSERT | VerifyChain | 成功（link 無し） | sqlite |
| compact が attested prompt を残す | hook 重複 prompt 2 行 | Compact | 両方残る。鎖が通る | sqlite |
| CLI に attest が無い | 現行 root | `attest` | unknown | cli |

### Risks / rollback

- 手続き化: persistEventDelivery に hash を直書きしない。domain 関数 + append helper。
- premature abstraction: scheme v2 / 複数チェーンは作らない。
- migration: 000061 は CREATE + genesis head のみ。store-sized scan なし。ConstantInPlace。
- 古いテスト fixture: テーブルが無ければ append は no-op。既存 Save 試験を壊さない。
- compact: attested DELETE を skip。RESTRICT はバグ網。
- rollback trigger: 新規 Save が Verify を壊したら merge しない。source を汚す経路は無い。
- 分割: #1678 が doctor / ファイル anchor。この PR は鎖だけ。
