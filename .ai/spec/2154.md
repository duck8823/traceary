# Issue 2154: doctor spool counters and --db-path scope labels

## Structure-Behavior Design Note

Risk: **Medium** — doctor stdout contract (golden `testdata/doctor/default.golden.json`); operator hint commands.

### Requirement summary
- 目的: metadata-only と full doctor の `hook-spool` 件数を比較可能にし、`--db-path` 付きで走った doctor の hint をそのまま実行しても同じ store を見る。
- 現状: 同一 spool で `pending=3442`（ファイル）と `990 件`（decoded records / client filter）が同じ check name。hint の `traceary doctor --fix` / memory activate に `--db-path` が無い。
- 期待する振る舞い:
  - metadata-only: 単位は **files**、ラベル `metadata-only` + `store-independent`。
  - full: 単位は **decoded records for the selected doctor client(s)**、同じ行に **filesystem pending files (store-independent)** を併記。
  - store-independent check の message に `store-independent` を含む。
  - `--db-path` または `TRACEARY_DB_PATH` で走ったとき、store-addressed な hint / `fix_command`（`traceary doctor|store|memory`）に `--db-path` を付ける。既定 home store では付けない。
- 非対象: JSON フィールド追加。spool の SQLite 化。large-store の追加 SQLite open。parent #2188 close。

### Conceptual model
| Concept | State | Behavior | Constraint |
|---|---|---|---|
| Metadata-only spool | ≥2 GiB doctor | file counts | no payload decode |
| Full spool | <2 GiB | decoded records + file count | client filter on records only |
| Explicit store | flag or TRACEARY_DB_PATH | rewrite store-addressed commands | host-only commands unchanged |
| Store-independent | hook/plugin/path/config | label in message | still `traceary doctor --fix` may need --db-path because --fix is whole-report |

### Responsibility assignment
| Responsibility | Owner | Not owner |
|---|---|---|
| File vs record wording | `inspectHookSpoolFilesystemMetadata` / `inspectHookSpoolDiagnosticsFromScan` | do not merge the two counters into one number |
| Scope label + --db-path rewrite | `annotateDoctorScopeAndDBPathHints` in finalize | do not scatter string concat at every inspect site |
| Explicit path detection | `doctorDBPathWasExplicit` | do not add --db-path for default home store |

### Boundaries / interfaces
| Boundary | Consumer | Hidden | Error |
|---|---|---|---|
| `doctorReport.hintDBPath` | finalize | not JSON | empty = no rewrite |
| `withDoctorInspectedDBPath` | FixCommand | shellQuote | skip if already has --db-path |
| doctor JSON | golden | message/hint/fix_command text may change | field names frozen |

### Behavior tests
| Behavior | Given | When | Then |
|---|---|---|---|
| Metadata labels | filesystem pending files | inspect metadata | message contains files + metadata-only + store-independent |
| Full dual unit | 1 decoded record | inspect full | message contains decoded records AND filesystem pending files |
| Explicit --db-path | memory-activation warn | doctor --json --db-path X | FixCommand and backticked hints include `--db-path X` |
| Default store | doctor without flag/env | doctor --json | FixCommand is `traceary doctor --fix` without --db-path |
| TRACEARY_DB_PATH | env set, no flag | doctor --json | store-addressed FixCommand includes --db-path |
| Host command | `claude plugins update` | annotate | unchanged |
| Golden | TestDoctor_JSON_Golden | --db-path fixture | snapshot updated same PR |
