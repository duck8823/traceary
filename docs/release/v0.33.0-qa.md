# v0.33.0 release QA

[日本語](./v0.33.0-qa.ja.md)

## Scope

This release validates bounded retrieval and scalable local-history access
without reading a live user store or publishing event bodies, prompts,
responses, cursors, workspaces, or spool payloads.

## Evidence

- The [multi-GiB evidence artifact](./v0.33.0-multigib-evidence.json) passes
  `go run ./cmd/repo-tooling release verify-body-free-evidence --input docs/release/v0.33.0-multigib-evidence.json`.
- The private synthetic probe records a Phase-A p95 of 0.079708 ms, below the
  fixed 250 ms release gate.
- The artifact also records copied migrations 31–34, projection rollback
  compatibility, FTS progress, bounded huge-body retrieval, and MCP aggregate
  response behavior.

## Release boundary

Migrations 31–34 are additive and maintain metadata access paths without
deleting existing event or session data. The tagged workflow must still run the
strict evidence verifier before publishing artifacts and close #1550 only after
the GitHub Release succeeds.

The synthetic migration fixture contains 130 events (including eight 256 MiB
rows), so it proves correctness and bounded behavior rather than real-store
backfill throughput at arbitrary row counts. The bounded-huge Phase-C p95 is
observational and has no release threshold.
