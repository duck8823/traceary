## Verdict

**Pass.** The complete #1558 evidence artifact passes every defined release
gate on Go 1.26.3, darwin/arm64. The 2 GiB projection-only direct metadata
benchmark measured p95 **0.077708 ms**, below the fixed **250 ms** target. The
copied migration, event/projection parity, incomplete/complete FTS probes,
aggregate response budget, six-package host parity, privacy, and scratch cleanup
also passed.

Phase-C latencies remain observations only because #1558 defines no release
threshold for them. This evidence removes the #1558 blocker; other v0.33.0
release gates remain independent.

This branch was rebased onto `main` at `6641c6d7`, which contains merged PRs
#1567 and #1570. No metric from the pre-projection blocked artifact was reused.

The machine-readable artifact is
[`v0.33.0-multigib-evidence.json`](./v0.33.0-multigib-evidence.json). It contains
metrics only.

## Procedure and privacy boundary

The maintainer-only runner:

1. requires at least 12 GiB of available scratch capacity;
2. creates an owner-only temporary directory;
3. runs the eight-event, 2 GiB projection-only metadata benchmark;
4. creates a synthetic pre-31 store, copies it, and applies migrations 31
   through 34 only to the copy;
5. verifies event/projection parity and records separate 25-run
   list/context/search series for metadata and bounded projections;
6. keeps incomplete and complete FTS search observations separate;
7. exercises a 100-item MCP request with multibyte canonical blocks and follows
   aggregate-budget continuations to completion;
8. verifies the same `traceary mcp-server` registration across six packaged
   hosts;
9. removes scratch storage before writing the final artifact.

The runner retains child output only in a capped in-memory buffer. The artifact
schema has no event/session identity, workspace, path, cursor, continuation,
body, prompt, or response field. Source/copy equality is checked internally;
the digest is not published.

Run and validate it with:

```sh
go run ./cmd/repo-tooling release run-v0.33.0-evidence \
  --output docs/release/v0.33.0-multigib-evidence.json

go run ./cmd/repo-tooling release verify-body-free-evidence \
  --input docs/release/v0.33.0-multigib-evidence.json
```

| Returned body bytes | 0 | 0 | pass |
| Measurement runs | 25 | 25 | pass |
| p95 | 0.077708 ms | below 250 ms | **pass** |

The fixture uses generated content-free SQLite extents and copies no user event
content. Fixture creation, migrations, checkpointing, extent checks, and
`EXPLAIN QUERY PLAN` execute before the 25 timers. Each sample contains only
query execution, complete row scanning, and row closure.

The plan uses `idx_event_metadata_workspace_created_at_norm_id_desc`, creates no
temporary sort, and does not consult the authoritative `events` table. The
trigger-maintained projection from merged PR #1570 therefore keeps metadata
selection independent of the 2 GiB body extent.

The previous pre-#1570 artifact measured the authoritative-table path and was
correctly blocked. A complete rerun, rather than metric substitution, produced
the passing result above.

This fixture deliberately represents the few-huge-rows shape: eight rows hold
2 GiB of body extents. It validates overflow-chain isolation but does not claim
coverage of the separate many-small-rows shape.

The source is synthetic and private. Only the copy is migrated. Large synthetic

Metadata projections returned zero body bytes. Incomplete and complete FTS

not serialized. These short, single-host series are not powered to compare
metadata and bounded projection performance; their p95 values are observations,
not relative-performance claims.

## Phases D and E

- A requested 100-item MCP page remained at or below 65,536 encoded body/block
  bytes. The observed maximum was 35 items and 65,536 bytes over three pages.
- All 100 multibyte canonical-block events appeared exactly once across the
  continuation chain.
- A body exceeding the requested per-event limit exposed `body_truncated` and
  its original `body_length`, while other canonical events retained
  `body_blocks`.
- All six packaged hosts passed the shared MCP command verifier.
- Scratch was private and absent before the artifact was written.

## Release disposition

The #1558 release gate is satisfied. A tagged release may use this artifact as
its multi-GiB body-free evidence, subject to the remaining independent release
checks. Rerun the entire workflow if the metadata projection, migrations 31-34,
FTS backfill, aggregate response budget, host manifests, or Go runtime changes.
Partial reuse is not valid because Phase-A and copied-migration timing depend on
the exact implementation and host.

For `v0.33.0`, the tagged-release workflow runs the strict artifact verifier
before GoReleaser. A missing, blocked, malformed, or privacy-invalid artifact
therefore stops publication rather than relying on an operator reminder.
