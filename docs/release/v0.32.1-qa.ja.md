# v0.32.1 release candidate の検証境界

[English](./v0.32.1-qa.md)

## 対象

v0.32.1 は、upgrade 後の host-plugin readiness と本文なし usage diagnostic の patch release です。#1519、#1521、#1522、#1523、#1532 を含みます。この release で privacy boundary は変わりません。Traceary は network interception、billing dashboard scraping、prompt/response body の capture を有効にしません。

## Candidate check

release preparation では version と対応する全 host manifest、日英ドキュメント、Go の build/test/lint suite、package 済み integration、release manifest の整合、whitespace error を検証します。tagged workflow は artifact build 前に release-manifest verification を再実行します。

candidate check は全 host の live availability を主張しません。本文なし evidence が unavailable または partial の host は、doctor と report output で明示分類したままにします。0 counter や推測した completion には変換しません。

## Artifact と Formula の所有者

`Formula/traceary.rb` は tagged release artifact から release workflow が生成します。この release-preparation PR では Formula URL も checksum も更新しません。tag 前には artifact value が存在しないためです。generation、checksum verification、後続の Formula commit は workflow が所有します。

## Review の制約

関連 PR では決定的 validation と独立した local review を実施しました。要求した external independent reviewer topology は有効な最終結果を返さず、maintainer はマージ済み PR の残リスクを明示的に了承しています。この記録は external-review coverage が充足されたとは扱いません。

## マージ後の release gate

`v0.32.1` を作成する前に、マージ済み candidate に対する refreshed-host dogfood と release QA check を実施し、release を止める follow-up を起票・解消します。tag は明示的な release authorization がある場合だけ作成します。
