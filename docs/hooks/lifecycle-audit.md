# Lifecycle compatibility audit — 2026-09-27

[日本語](lifecycle-audit.ja.md)

This is a documentation-derived audit, not a live-capture certification. Existing observed flags and historical fixtures remain unchanged. Stop ends a turn, not a session. Interrupt and StopFailure write only fixed notes; sessions remain open. Payload errors and partial assistant messages are discarded before durable spooling. No permission, telemetry, task, heartbeat or model-switch subscriptions are added.

## Retry, cleanup and rollback

Codex SessionEnd is a physical runtime close observation, not the irreversible terminal boundary of a resumable logical thread. Session aggregates and global fallback state remain unchanged; native payload identity is authoritative and Interrupt targets the main session, not an active child. Passive notes use proven native delivery identifiers where provided, never an invented body hash. Logical close/resume semantics require a separate design checkpoint: [follow-up #2394](https://github.com/duck8823/traceary/issues/2394). Existing explicit terminal cleanup and maintenance behavior is unchanged; no atomic-cleanup guarantee is added. Explicit one-shot wrapper identity overrides a present native session ID for note attribution, but missing native identity remains a no-op.

Prerequisite: [#2395](https://github.com/duck8823/traceary/issues/2395), merged through [PR #2396](https://github.com/duck8823/traceary/pull/2396), isolates wall-clock budget measurements from parallel test load and starts attestation deadlines after fixture setup. Production retry behavior and timing thresholds are unchanged. It is a separate issue/PR, not bundled here; fresh CI still verifies elapsed-time safety.

Rollback is one issue PR revert; no DB migration or installed host configuration change is required. Fixed notes already recorded remain harmless history.

## Host and Traceary version requirements

New subscriptions require a host implementing the current official lifecycle contract. Verify or update the host before refreshing hooks. Historical Codex 0.145.0 live fixtures do not certify SessionEnd/Interrupt support; this audit provides neither a minimum introduction-version guarantee nor live certification. The new passive CLI adapter is available in this HEAD build / the next Traceary release, not the already installed 0.52.0 binary. This change does not update installed binaries or host settings.
