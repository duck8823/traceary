# Cockpit dogfood checklist (historical)

[日本語](./cockpit-dogfood.ja.md)

> **Historical.** The operator cockpit and its dogfood golden suite were removed in v0.35.0 (#1764). Do not run `TestCockpitDogfood` or treat this checklist as a release gate. For remaining interactive surfaces, dogfood `traceary list`, `traceary search`, `traceary memory inbox review`, and `traceary list --follow` as needed. Orphan `~/.local/state/traceary/cockpit.json` (or `$XDG_STATE_HOME/traceary/cockpit.json`) is safe to delete manually.

This path remains only as a historical pointer to the former release dogfood process for `traceary tui`.
